IN A REAL-WORLD PROJECT WE HAVE THREE MAIN ENTITIES:
1.CLIENT->me
2.SERVER->shopkeeper
3.DATABASE->shop

IN SERVER WE HAVE THREE LAYERS IN IT:
1.CONTROLLER
2.SERVICE
3.REPOSITORY


NORMAL FLOW OF THOSE THREE ENTITIES:
CLIENT-----(DATA)--->SERVER------>DATABASE----(DATA)--->SERVER---->CLIENT(DATA)
WHATS HAPPENING IN SERVER?
SERVER IS RESPONSIBLE FOR REQUESTING AND PERFORMING THE REQUESTS OF A CLIENT
AND INSIDE SERVER WHAT HAPPENS IN EACH LAYER:

1.CONTROLLER-LAYER:
CONTROLLER JOB IS TO WORK WITH CLIENT'S REQUEST AND PASSES THE CONTROLL BASED ON THE REQUEST REQUIREMENT
CONTROLLER BASICALLY WORKS ON REQUEST AND SENDS BACK THE RESPONSE TO CLIENT

2.SERVICE-LAYER:
SERVICE LAYER PROCESSES THE REQUEST FROM CLIENT

3.REPSOITORY-LAYER:
SERVICE LAYER PROCCESES BUT IT DOESNT HAVE DATA INIT
FOR THAT IT NEED TO CONNECT WITH A DATABASE
IN SUCH CASE WE HAVE A LAYER CALLED "DOA(DATA ACCESS OBJECT)" WHICH IS NOTHING BUT REPOSITORY LAYER

REPOSITORY LAYER IS RESPONSIBLE TO INTERACT WITH DATABASE AND RETURN DATA TO SERVICE LAYER
